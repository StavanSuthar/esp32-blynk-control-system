# ESP32 Blynk Control System

## Overview
This project uses ESP32 and Blynk to control a 7-segment display over Wi-Fi.

## Features
- Real-time mobile control
- Wi-Fi communication
- GPIO output handling
- Hardware-software integration

## Technologies Used
- ESP32
- Arduino IDE
- Blynk
- Embedded C

## Learning Outcomes
- ESP32 Wi-Fi setup
- GPIO pin mapping
- Embedded debugging
- IoT communication basics

## Future Improvements
- Add sensor integration
- Improve UI
- Add cloud telemetry support
